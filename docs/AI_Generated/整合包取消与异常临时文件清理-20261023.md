# 整合包取消与异常临时文件清理

## 问题与行为

整合包预览下载的 `.mrpack` 原先由安装侧栏持有，取消或失败时只有关闭侧栏才会删除。现在安装流程退出后立即释放该文件、清空包引用和 `HasPackage` 状态；异常界面打开之前就完成清理。取消后点击安装会重新获取整合包，再创建新的安装任务。

导入与图标下载继续并行执行。每次安装建立连接到任务中心令牌的取消源；导入失败或取消时停止图标请求并等待其退出，观察其异常。图标本身为可选内容，下载失败不改变已成功导入的结果。

## 改动文件

- `OneLauncher/ViewModels/Panes/InstallPackPaneViewModel.cs`：统一 `ReleasePackage`，覆盖信息解析异常、安装取消/失败和关闭侧栏；重试重新加载包；等待并行图标下载退出；过滤已退出任务的进度回调。
- `ConsoleTest/ConsoleTest.csproj`、`ConsoleTest/Program.cs`：增加 `--modpack-cleanup` 离线入口，链接已有整合包侧栏夹具和所需 Avalonia 无界面依赖，不初始化真实启动器数据。
- `ConsoleTest/README.md`：记录运行方式。
- `tests/OneLauncher.RegressionTests/ModpackUiChecks.cs`：复用已有场景，新增侧栏仍打开及异常弹窗仍打开时的清理断言，验证重新下载重试、图标请求终止和已登记实例保留；测试临时目录设在本次工作区输出目录内。

## 清理顺序与边界

等待 `ImportModpack` 完成或抛出，再释放包文件，避免安装仍在读取 ZIP 时删除文件。现有导入器通过 `using` 清理解压目录，下载器清理 `.downloading`，图标写入的 `finally` 清理 `customicon.*.tmp`；本次补齐侧栏持有的原始包文件以及并行请求的生命周期。

未改动 `ModpackImporter`、`MrpackParser`、`ModpackExporter`、`PackImportModels`、`UnitedCore` 或 Download 组件。清理只释放本次持有的临时资源，不扫描或删除游戏实例和共享版本目录；已返回的 `GameData` 继续保留，避免迟到取消导致重复导入。

`ReleasePackage` 集中管理包引用，后续增加失败出口时可直接复用。文件删除继续使用 `ModpackDownload.Dispose` 的既有错误处理，不让清理异常替换安装异常。

## 验证

```powershell
dotnet build ConsoleTest/ConsoleTest.csproj --nologo -v minimal -clp:ErrorsOnly
dotnet ConsoleTest/bin/Debug/net10.0/ConsoleTest.dll --modpack-cleanup --output build/modpack-cleanup-20261023
```

构建成功，0 错误（246 个编译警告）。离线检查退出码 0，覆盖侧栏取消、任务中心取消、预览取消、下载失败与未关闭异常弹窗、并行图标取消、重新下载重试、迟到取消、可选图标失败、并发安装及截图。取消和失败场景检查 `.mrpack`、解压目录、`.downloading` 和图标写入临时文件均无残留。

输出目录：`build/modpack-cleanup-20261023`，测试包文件、解压目录、实例数据和截图均位于工作区内。
