# Page 与 Pane 接口统一适配

## 目的

使用现有 `IPageHost`、`IListTemplate<T>` 和 `IPaneHost` 统一前端页面的侧栏、列表刷新和 Pane 关闭契约。接口本身保持用户定义。

## 修改范围

八个 PageViewModel 均实现 `IPageHost` 和 `IListTemplate<T>`：

| 页面 | Items 元素类型 | 刷新行为 |
| --- | --- | --- |
| AccountPageViewModel | UserItem | 从账户管理器重建账户展示列表 |
| DownloadPageViewModel | VersionBasicInfo | 从 UnitedCore 的版本清单重建列表 |
| GameDataPageViewModel | GameDataItem | 重建实例列表及可用标签 |
| HomePageViewModel | GameData | 重建启动实例选项 |
| ModsBrowserViewModel | ModItem | 使用当前搜索文本请求 Modrinth 搜索结果 |
| ServerPageViewModel | ServerItem | 从收藏与当前延迟缓存重建展示列表 |
| SettingsPageViewModel | NavigationVisibilityItem | 按设置重建导航可见性编辑项 |
| VersionPageViewModel | VersionItem | 从版本管理器重建展示列表 |

这些文件位于 `OneLauncher/ViewModels/Pages`。版本页面先前误加在 `VersionItem` 上的接口声明移至 `VersionPageViewModel`，列表项不承担页面宿主职责。BaseViewModel 和其他列表项保持原职责。

所有页面主列表改为带 `[ObservableProperty]` 的 `ObservableCollection<T> items`，生成公开、可读写且带通知的 `Items` 属性。八个对应 `OneLauncher/Views/Pages/*.axaml` 的绑定同步修改。标签、设置分类和下载源等辅助集合保留各自名称。

下载、模组检索、版本页面原先名为 `DownloadPaneContent`、`InstallModPaneContent`、`RefDownPane` 的侧栏内容统一为 `PaneContent`。侧栏属性继续使用源生成器发送变更通知，没有退回普通自动属性。

十三个 `OneLauncher/ViewModels/Panes/*PaneViewModel.cs` 实现 `IPaneHost`：AddServer、Download、EditGameData、EditServer、GameDataModsManager、InitServer、InstallMod、JavaInstall、NewGameData、PowerPlay、SkinManger、TaskCenter、UserModelLogin。原私有关闭回调字段替换为公开 `Action OnPaneClose { get; init; }`，构造函数仍接收原回调参数。已有关闭、返回、取消、保存完成入口改为调用此属性，保持原取消任务和资源清理逻辑。Pane 的视图无需重复实现 ViewModel 的回调契约，工厂与命令绑定无需改名。

## 刷新与异步调用

`RefList()` 统一为公开 `Task` 方法。Modrinth 的原搜索方法更名为 `RefList`，对应按钮及 Enter 键绑定改为生成的 `RefListCommand`；账户的 `RefreshCommand` 保留下载皮肤缓存的完整操作，与单纯重建列表区分。

集合更新在 UI 线程执行；后台调用通过 Dispatcher 调度。调用方可以 `await RefList()` 等待集合完成更新，避免仅提交 Post 就报告刷新完成。构造函数和同步数据变更事件通过 `_ = RefList()` 调用，事件使用独立的 void 回调适配 Task 返回值，保留原有订阅与取消订阅关系。

账户设为默认、删除账户、刷新缓存以及皮肤上传后的列表刷新使用 await。皮肤管理 Pane 的两处调用已同步更新。下载页仍读取已初始化的 MojangVersionList，本次没有改变为每次重新联网获取清单。

## 扩展方法

新 Page 可参照上述结构实现两个页面接口，选择对应主列表的展示类型。使用 `[ObservableProperty]` 字段生成接口要求的公开属性，新增同步事件时用独立回调调用刷新方法。接口提供成员契约，具体的数据源与错误处理仍由页面决定。

新 Pane 实现 `IPaneHost` 并接收关闭回调。关闭回调默认空操作兼容已有设计模式和允许省略回调的构造函数；实际宿主通过现有工厂传入设置 `IsPaneShow = false` 的回调，也可以在对象初始化器中指定 `OnPaneClose`。需要取消任务或清理资源的关闭命令应保留这些步骤，再调用回调。
