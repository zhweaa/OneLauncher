# 整合包资源检索与独立安装侧栏实现

日期：2026-10-23。

## 功能与使用

资源检索页面的类型下拉框增加“整合包”。选择该类型并搜索后，点击资源卡片的“安装”会打开新的 `InstallPackPane`。侧栏先获取整合包信息，不创建实例；信息准备好后点击侧栏“安装”，才执行导入并创建新实例。

侧栏使用既有 `PaneHeader`、`pane-divider`、`pane-surface`、`pane-status`、`pane-progress` 和底部操作按钮样式。内容只有整合包信息、安装进度两部分：显示清单名称、Minecraft 版本、加载器及其版本；描述沿用搜索结果。加载信息失败可重新加载，安装中可取消，成功后通过“完成”关闭。

沿用资源检索原有搜索框、下拉框、搜索按钮横向布局，搜索区域未恢复进度条。整合包安装不复用 `InstallModPane`，模组与光影继续使用原侧栏。

## 后端入口与解析器复用

`ResourceInstallerService.GetModpackInfoAsync(projectId, cancellationToken)` 获取 Modrinth 项目版本列表的第一项，选取其中 `.mrpack` 文件，优先使用标记为 primary 的文件。接口返回 `ModpackDownload`，包含已下载的临时包文件及 `MrpackParser`，由调用方负责释放。

`.mrpack` 是 ZIP，`MrpackParser` 接收的是包内 `modrinth.index.json` 的 JSON 流，因此不能把整个 ZIP 网络流直接作为清单解析。新增获取组件把网络流异步写入唯一临时文件，再打开 ZIP 清单条目流交给现有解析器。这样支持不能 Seek 的 HTTP 流，也避免安装时重复下载整个包。启用全局 SHA1 选项且 API 提供哈希时，校验下载的包文件。

`ResourceInstallerService.ImportModpack(package, progress, cancellationToken)` 把同一个临时包和解析器传给原有 `ModpackImporter.ImportFromMrpackAsync`。

为实现复用，导入器仅增加可选 `MrpackParser` 构造参数及对应字段，静态入口增加同样的尾部可选参数；解压后使用传入解析器，未传入时仍读取本地清单创建解析器。既有首页本地 `.mrpack` 导入调用保持兼容。

临时包在加载失败、加载取消、关闭侧栏时清理；安装尚未退出时关闭侧栏，会先取消任务，等导入方法退出后再释放 ZIP，避免文件清理与解压竞争。

## 任务与取消

整合包安装复用既有 `TaskManager`，将任务令牌传给 `ResourceInstallerService` 和原有导入流程。基础版本安装继续通过 `VersionInstallerService` 创建 `DownloadMinecraft` 时传入令牌，未向 `DownloadInfo` 增加令牌字段或参数。

新侧栏和 `InstallModPane` 都订阅当前任务的取消事件。侧栏按钮或任务中心发起取消后，会立即显示“正在取消”，禁用重复取消；实际安装方法退出后显示“已取消”。返回侧栏会取消当前操作。

进度更新核对任务身份、运行状态和侧栏是否仍在安装；运行中的百分比最多显示 99%，导入成功返回且令牌未取消时才设置 100% 和完成。异常进入失败任务及既有 `OlanExceptionWorker`，取消独立处理，允许失败、取消后重试。安装完成后禁用重复导入。

## 约束核对与当前边界

- `UnitedCore.cs` 与开始改动前内容一致；未改任何 Download 组件，已对该目录全部文件哈希进行前后核对。取消仍走 `DownloadMinecraft` 原有构造参数。
- `MrpackParser`、`ModpackExporter`、清单模型除了目录及命名空间外无行为变化；导入器除了上述解析器复用外无业务变化；未新增或修改 `PackImportModels`。
- 本次未实现自定义加载器版本安装，导入仍使用原有基础版本选择逻辑。侧栏显示清单要求的加载器版本，并不表示下载组件已支持精确安装这个版本。
- 原导入器的同步解压、元数据准备等阶段，取消响应仍受现有取消检查位置限制；失败或取消可能残留未登记的实例目录。其清单文件校验、环境筛选、覆盖优先级、加载器冲突、导出范围等探索文档中的其他改造均未执行。
- 新入口默认使用接口返回的第一项包版本，没有增加历史发行版选择、本地文件选择或新实例自定义命名选项；既有首页本地导入入口保留。

后续如扩展格式和来源，可在资源获取组件中生成同样的包文件与解析器对象，再调用统一导入入口；修改加载器、清单或回滚行为应另行处理原导入组件，避免在 UI 中复制导入逻辑。
