# 支持版本 ListBox 只读交互修复

日期：2026-10-23。

## 用意与改动

“支持的版本”用于展示资源支持的 Minecraft 版本，不需要通过列表选择安装版本。按用户要求保留 `ListBox`，继续使用 `OneLauncher/Styles/TransparentListBox.axaml` 已定义的 `card-list` 样式。

`card-list` 负责透明容器、条目间距和透明选中背景，本身不禁止逻辑选择。此次在 `OneLauncher/Views/Panes/InstallModPane.axaml` 的版本列表中设置 `Focusable="False"`，并使用局部 `ListBoxItem` 样式设置 `IsHitTestVisible="False"`、`Focusable="False"`，避免版本项接受指针点击和键盘焦点。列表本身继续接收滚动交互，未整体禁用控件，因此不引入禁用文字效果。

既有 `InstallModPaneViewModel` 在复制支持版本后调用 `Reverse()`，本次保留该倒序逻辑，不修改原始资源的版本集合。模组和光影包共用此视图。

## 文件与扩展边界

- `OneLauncher/Views/Panes/InstallModPane.axaml`：仅补充版本列表的只读交互设置。
- 本文：记录变更用意、逻辑和验证结果。

局部样式只作用于当前版本列表。公共 `card-list` 仍可用于有选择或按钮操作的页面列表；后续修改卡片外观继续维护 `TransparentListBox.axaml`，不要将该版本列表的只读行为推广到所有列表。
