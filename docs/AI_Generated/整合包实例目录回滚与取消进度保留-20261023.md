# 整合包实例目录回滚与取消进度保留

## 原因

上一次清理覆盖了 `.mrpack`、解压目录和下载临时文件，但导入器在下载前就创建实例目录、复制 overrides。取消或失败后，这个尚未登记的实例目录仍存在。本次补齐实例目录的回滚。

## 改动

- `OneLauncher.Core/DefaultComponent/Resource/Pack/ModpackImporter.cs`：在创建目录前固定其绝对路径，确认它直接位于当前游戏根目录的 `instance` 内，且目录、文件和实例 ID 尚未存在。将目录创建、文件安装及实例登记纳入同一个异常处理范围；保存登记成功后设置完成标记。
- 登记成功前出现取消或异常时，删除本次创建的实例目录。若 `AddGameDataAsync` 已更新内存但保存失败，先通过既有 `RemoveGameDataAsync` 撤销本次登记。清理异常记录日志，保留原始安装异常。
- 导入器的登记与失败回滚通过共享异步锁串行执行，避免多个导入同时更新实例字典；下载过程仍可并行。等待登记期间同样响应取消。
- `OneLauncher/ViewModels/Panes/InstallPackPaneViewModel.cs`：取消安装、任务中心取消以及取消预览时，不再用取消提示覆盖 `CurrentText`。状态图标旁继续显示“正在取消”或“已取消”，“当前进度”保留最后的文件或步骤；已退出任务的进度回调继续被过滤。
- `tests/OneLauncher.RegressionTests/ModpackUiChecks.cs`：扩展 ConsoleTest 复用的夹具，检查实例目录集合与已登记实例对应，验证既有未登记目录仍保留、取消文字不重复、登记保存失败时内存和目录同时回滚；并发检查增加超时和错误检查。
- `ConsoleTest/README.md`：补充实例目录回滚和进度文字的验证范围。

## 边界与后续扩展

清理只针对本次创建、尚未成功登记的目录，不扫描历史孤立目录，不删除已有实例或共享游戏版本。成功登记后的迟到取消仍保留完整实例。未来在导入流程中增加安装步骤，应放在登记成功之前的异常处理范围内，以复用回滚逻辑。

本次仅针对该问题调整导入器的异常处理与登记顺序，未修改解析器、导出器、PackImportModels、UnitedCore 或 Download 组件。

## 验证

```powershell
dotnet build ConsoleTest/ConsoleTest.csproj --no-restore --nologo -v minimal -clp:ErrorsOnly
dotnet ConsoleTest/bin/Debug/net10.0/ConsoleTest.dll --modpack-cleanup --output build/modpack-instance-rollback-20261023/final
```

最终构建通过，0 错误。ConsoleTest 离线检查退出码 0，覆盖取消、关闭侧栏、任务中心取消、下载异常、登记保存异常、重试、既有目录保留、成功实例保留、并发导入及取消进度文字。测试文件和临时目录均位于工作区内的指定输出目录。
