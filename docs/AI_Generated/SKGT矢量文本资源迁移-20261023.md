# SKGT 矢量文本资源迁移

## 目的与范围

将生产代码中分散的矢量路径文本统一保存到用户创建的 `OneLauncher/Assets/Resources/SKGT.resx`。检索 UI、Core、Desktop、Console、Core.Net 和 Jvm 的 C#/AXAML 源码后，找到 18 处路径文本，去重后为 9 个资源；其他项目没有这些矢量文本的使用点。

保留原有路径文本，任务中心的取消与失败原本使用相同路径，迁移后共用一个资源。下载/安装的状态图形与任务中心虽然语义类似，原始路径文本并不完全相同，因此分别保存。用户已有的 `TEST=TEST1` 条目保留。

## 资源与应用点

| SKGT 资源键 | 图形用途 | 消费者 |
|---|---|---|
| `StatusRunning` | 圆形时钟，等待/运行状态 | DownloadPaneViewModel、InstallModPaneViewModel、InstallPackPaneViewModel |
| `StatusCompleted` | 圆形对勾，完成状态 | 同上 |
| `StatusCanceled` | 圆形叉号，取消状态 | 同上 |
| `StatusFailed` | 三角警告，失败状态 | 同上 |
| `ChevronLeft` | 新闻上一条 | Home.axaml |
| `ChevronRight` | 新闻下一条 | Home.axaml |
| `TaskRunning` | 任务运行的刷新箭头 | TaskCenterPane.axaml |
| `TaskStopped` | 任务取消或异常的圆形叉号 | TaskCenterPane.axaml 的 canceled、failed 图标 |
| `TaskCompleted` | 任务完成的圆形对勾 | TaskCenterPane.axaml |

## 加载与共享逻辑

原项目把 `SKGT.resx` 作为 AvaloniaResource，并排除了 EmbeddedResource 处理，原有小写 `skgt.Designer.cs` 的 ResourceManager 名称与文件大小写也不同。这种配置不能用于正常的 .NET 强类型资源读取。

`OneLauncher.csproj` 现在按 .NET EmbeddedResource 处理 SKGT，显式采用 `OneLauncher.Assets.Resources.SKGT` 名称，避免大小写不一致。MSBuild 的标准 GenerateResource 任务在每次构建时生成 `obj/<配置>/<目标框架>/SKGT.Designer.cs`，类型为 `OneLauncher.Assets.Resources.SKGT`。资源内容只在 resx 中维护，不依赖 Visual Studio 才能重新生成属性。旧的、不包含矢量属性的小写 Designer 文件移除，Resources 目录不再重复打包到 Avalonia 资源中。

新增 `VectorIcons.cs` 为每个资源提供只读的静态 Geometry 属性，使用生成的 SKGT 字符串属性调用 `Geometry.Parse`，在类型初始化时解析一次。多个控件和 ViewModel 共用已经解析的 Geometry，不在状态属性读取时重复解析路径。

AXAML 使用返回 Geometry 的静态属性：

```xml
xmlns:icons="using:OneLauncher.Assets.Resources"
```

```xml
<PathIcon Data="{x:Static icons:VectorIcons.ChevronLeft}" Width="16" Height="16"/>
```

ViewModel 状态分支继续返回 Geometry，例如完成状态返回 `VectorIcons.StatusCompleted`。已有 `StatusIcon` 绑定、通知、Foreground、尺寸、IsVisible 和状态逻辑保留。Geometry 仅描述轮廓，颜色继续由主题或业务状态画刷决定，不随此迁移写入 resx。

共享 Geometry 作为图标定义使用，不应被调用者修改 Transform 等属性。如果某个控件需要独立修改 Geometry，应使用副本而不是修改共享对象。

## 修改文件

- `OneLauncher/Assets/Resources/SKGT.resx`：增加 9 个路径字符串及用途注释。
- `OneLauncher/OneLauncher.csproj`：修正资源类型、名称和自动生成配置。
- `OneLauncher/Assets/Resources/VectorIcons.cs`：新增共享 Geometry 访问层。
- `OneLauncher/Assets/Resources/skgt.Designer.cs`：移除旧文件，改为标准构建自动生成。
- `OneLauncher/Views/Pages/Home.axaml`：两个翻页 PathIcon 改为静态 Geometry 引用。
- `OneLauncher/Views/Panes/TaskCenterPane.axaml`：四个状态 PathIcon 改为静态 Geometry 引用。
- `OneLauncher/ViewModels/Panes/DownloadPaneViewModel.cs`：移除四份路径文本，返回共享状态图形。
- `OneLauncher/ViewModels/Panes/InstallModPaneViewModel.cs`：同上。
- `OneLauncher/ViewModels/Panes/InstallPackPaneViewModel.cs`：状态分支直接返回共享 Geometry，不再每次读取都解析文本。
- `docs/AI_Generated/UI_FI_Style.md`：补充矢量资源存储与引用约定。
- 本文档及 `build/skgt-resources-20261023` 下的独立验证资料。

## 后续扩展

新增矢量图时，在 SKGT.resx 增加一个有明确用途的字符串资源键，在 VectorIcons 增加同名 Geometry 属性，然后使用该属性。修改已有图形只需改对应 resx 值并重新构建。不要直接编辑 obj 下生成的 Designer 文件；不要在业务 ViewModel 或 AXAML 中重新复制原始路径文本。

此处保存的是不随语言变化的几何定义。当前图形来自中性 resx，验证了 zh-CN、en-US 的资源回退；业务文字本地化应独立规划，不需要为图标添加语言副本。

## 验证与边界

- UI 项目编译成功，资源强类型属性和 AXAML 静态访问通过编译。
- 扫描生产 C#/AXAML 确认不存在残留的路径字符串字面量；路径保存在 SKGT.resx，生成的 obj 文件属于构建产物。
- 迁移前保存每种路径的 SHA-256，验证 resx 和实际嵌入资源中的字符串与原始内容相同。
- 验证 `OneLauncher.Assets.Resources.SKGT.resources` 在程序集内存在，保留 TEST 条目，语言回退正常，9 个 Geometry 有效且重复读取返回缓存对象。
- 验证三个 ViewModel 的 Running/Finished/Canceled/Failed，共 12 个状态分支，均返回对应的共享 Geometry。
- 加载实际 Home 与 TaskCenterPane AXAML，检查翻页图形、16 个已实例化的任务状态 PathIcon 以及四个状态各显示一个图标。
- 渲染图形画廊和真实任务中心的 Light/Dark 图像，检查路径迁移后的图形显示。

验证程序位于 `build/skgt-resources-20261023/Program.cs`，只使用临时任务对象，不启动游戏、不联网、不加载真实用户数据。`baseline.json` 保存原始路径内容哈希。Validation.targets 临时替换回归测试项目的编译输入，仅运行本次专用验证；原有测试源文件不被修改。这不是全项目业务回归测试。
