# 整合包启动路径与安装侧栏改进实现

日期：2026-10-23。落实《整合包启动路径与安装侧栏改进行动文档》，并依照后续指示由 `InstallPackPaneViewModel` 直接给返回实例设置图标。同步修复 `VectorIcons` 迁移到 `Converters` 后的编译问题。

## 改动与行为

### 启动目录

`GameLauncher.BasicLaunch` 计算一次 `launchGamePath`，同时用于 `SetGamePath` 和 Java `ProcessStartInfo.WorkingDirectory`。普通启动使用实例目录；根目录模式使用游戏根目录。共享 assets、libraries、版本主文件和 natives 继续按现有根目录绝对路径使用。

此前 FancyMenu 使用相对配置路径，但 Java 工作目录指向根目录，配置却在实例内，最终造成 Drippy Loading Screen 初始化空引用。此次修正目录选择，不改整合包内容或加载器安装组件。

### 实例图标

用户已将导入器改为返回 `GameData`。服务入口最终为 `Task<GameData> ImportModpack(...)`，直接返回原导入器结果，保留入口取消检查；删除曾位于 return 后的不可执行检查。实例登记已经完成后，服务不再丢弃成功返回的实例身份。

`InstallPackPaneViewModel` 在同一个安装任务内，使用搜索结果已有的 `ResourceItem.IconUrl` 获取图片。UI 使用专用共享 `HttpClient`，超时 20 秒；没有增加 Core 服务或公开原有内部下载器。只接受 HTTP/HTTPS URL；图片在进入导入流程前读取并用 Avalonia Bitmap 验证。任务令牌取消时正常退出，创建实例前的取消不会因为图标被误当作可选错误而忽略。

导入成功后，直接写入返回的 `<InstancePath>/.olc/customicon`：先写唯一临时文件，再替换目标，避免下载失败或不完整图片破坏已有图标。保存实例管理器触发现有数据更新事件，让已打开的实例列表刷新；主页和编辑实例继续使用既有图标读取逻辑，重启后也能读取该文件。

没有图标、图片无效、图标 HTTP 请求或可选写入失败时，保留包内原有图标或默认图标，并发出简短通知；已成功登记的整合包不会因可选图标失败变为允许重复安装的失败任务。原 `.mrpack` 文件和其 SHA1 校验内容保持不变，不创建带图标的包副本。

侧栏保存本次已导入实例的引用。若实例已登记、图标写入后的刷新阶段收到取消，任务保持取消状态，明确告知已导入实例保留，并禁用重复导入；仍可通过同位置的完成按钮关闭。任务中心与侧栏始终使用同一 TaskInstance。

### 侧栏

下载侧栏新增等待、下载中、取消中、取消、失败、完成状态文字及矢量图标，状态卡片采用现有主题颜色。图标使用迁移后的 `VectorIcons`，路径文本由 `SKGT.resx` 管理。安装选项在任务运行时禁用。

下载回调收到安装服务的 Done 时，只提示正在登记实例。实例登记并设置默认实例成功后，才把任务设为完成和 100%。失败在 Debug/Release 下都进入既有异常界面，取消单独处理；任务中心取消立即反映到侧栏，取消按钮在任务退出前禁用重复点击。失败或取消后可重试，完成后禁止再次下载；每次退出解除取消事件订阅，旧进度核对任务身份及运行状态，不能覆盖终态。

`DownloadPane`、`InstallPackPane`、共用 `InstallModPane` 底部采用固定双列等宽操作区，左取消、右执行。按钮始终保留位置，通过命令可执行条件启用；整合包完成后右侧同位置显示完成。信息重新加载仍是独立辅助操作。内容区保持可滚动，底部操作不会被挤出窗口。

### VectorIcons 编译修复

`VectorIcons.cs` 已迁移到 `OneLauncher/Converters`，类命名空间为 `OneLauncher.Converters`，而 MSBuild 生成的 SKGT 类仍位于 `OneLauncher.Assets.Resources`。为 VectorIcons 增加明确的 SKGT 类型别名；主页及任务中心 AXAML 的 `xmlns:icons` 同步到新命名空间。保留另一位 Agent 的矢量图资源迁移成果。

### 原整合包启动复测

经用户允许，使用保存的原启动参数重放 Minecraft 1.20.1 / Forge 47.4.28 实例 `6a710be5`，Java 工作目录修正为该实例目录。实际游戏运行约 84 秒后正常退出，退出码 0，没有达到观察超时或被测试脚本强制结束。

本次日志未出现原 FancyMenu 配置路径 IOException、`customizableScreens` 空引用或崩溃报告保存提示；已有资源重载、OpenAL 初始化、声音引擎启动和正常 Stopping 记录。原问题的路径原因通过真实启动复测得到验证。日志中仍有 AllTheLeaks 等模组自身的其他错误记录，此次未修改这些模组；没有测试进入世界或联机，也不把正常启动等同于整合包所有功能均无错误。

重放脚本和经过 accessToken 脱敏的输出位于 `build/pack-improvements-20261023/ReplayModpack.ps1` 和 `real-modpack-launch.log`。该重放检查与 Java 探针分开：探针验证生产 GameLauncher 路径选择，重放验证原实例相对配置错误已经消失。

## 后续扩展

新的资源来源可以提供不同 IconUrl，并继续沿用前端对返回实例的图标设置流程。包格式、加载器版本、回滚及清单筛选仍应在相应后端组件独立扩展，侧栏不复制导入逻辑。未来如调整 VectorIcons 位置，需要同步其命名空间、C# using 与 AXAML x:Static 引用，SKGT 生成命名空间以项目文件配置为准。
