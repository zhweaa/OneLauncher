# 图标深浅色主题适配

## 用意与实现

项目的界面图标位于 `OneLauncher/Assets/icos`，共 21 个 PNG。此前 AXAML 直接引用原图，深色模式下黑色图标不随文字颜色变化。

新增 `scripts/Generate-ThemeIcons.ps1`，读取该目录第一层的 PNG，将 RGB 改为白色，保持图片尺寸和每一个像素的 alpha 值，输出到 `OneLauncher/Assets/icos/white`。直接保留 alpha 可以保留透明背景和抗锯齿边缘。原图不被修改，包括浅色模式下原有的红色删除和错误图标。

脚本同时更新 `OneLauncher/Styles/Theme.axaml` 中的图标资源。图标与颜色资源统一存放在现有的 `Light` 和 `Dark` 主题字典中，使用相同资源键，例如 `IconHome`：浅色主题加载原图，深色主题加载白色副本。Avalonia 的 Bitmap 资源使用元素文本指定 `avares://` URI，通过图片类型转换器加载，不使用 `UriSource` 属性。

`App.axaml` 通过原有的 `Theme.axaml` 引用加载全部主题资源，不再单独加载 `Icons.axaml`。各个图标位置使用 `Source="{DynamicResource IconHome}"` 等引用。动态资源随控件的实际主题更新，可继承应用、窗口及父控件的主题，也支持运行时切换。保留现有 `RequestedThemeVariant="Default"`，继续采用现有系统主题机制，无须新增 ViewModel、事件监听或转换器。

## 使用与扩展

在项目根目录的 Windows PowerShell 5.1 或 PowerShell 7 中运行：

```powershell
pwsh -File scripts/Generate-ThemeIcons.ps1
```

脚本依赖 Windows 自带的 System.Drawing，不需要额外图像处理工具。可用 `-ProjectRoot` 指定仓库根目录。

增加或替换图标后重新运行脚本，提交原图、白色副本和字典。资源键由文件名派生，例如 `save.png` 对应 `IconSave`，`settings1.png` 对应 `IconSettings1`。文件名应以字母开头且仅包含字母和数字；脚本会拒绝不合规名称及重复资源键。新图标在 AXAML 中使用对应 `DynamicResource` 即可。

脚本只扫描原图目录第一层，不会再次处理 white 子目录，重复运行会生成相同内容。手工删除原图时也应删除对应的 white 副本；图标资源会根据当前原图列表重新生成。

`Theme.axaml` 中两组图标分别位于 `BEGIN GENERATED ICONS: Light/Dark` 与对应 `END GENERATED ICONS` 注释之间。脚本只替换这些标记区块，保留区块之外的颜色、间距和其他手工维护资源以及文件换行格式。不要删除区块标记；找不到唯一的区块时，脚本会在写入任何生成文件之前报错。无需再维护独立的图标资源文件。

- 合并到 `Theme.axaml` 后，验证图标区块之外的手工主题内容逐字符不变，重复生成的文件哈希一致，独立图标字典已移除；重新编译并通过全部主题切换验证。
- 编译 UI 及专用验证程序成功，0 个错误。项目已有编译警告仍存在。
- 全项目检索确认，资源字典之外没有 AXAML 继续直接引用 `Assets/icos` 图片路径。
- 使用真实 App 资源及 Avalonia Headless/Skia 验证 21 组 Bitmap 资源、Light → Dark → Light 动态更新、真实账户页按钮、PaneHeader 模板、窗口继承应用主题。
- 渲染并目视检查 `build/theme-icons-20261023/icons-light.png` 与 `icons-dark.png`，图标、按钮及公共 Pane 返回图标均显示正常。

专用验证源码与 MSBuild 注入配置位于 `build/theme-icons-20261023/Program.cs`、`Validation.targets`。它复用现有回归测试项目的依赖，不修改原有测试源文件，不初始化启动器服务或访问真实用户数据：

```powershell
dotnet build tests/OneLauncher.RegressionTests/OneLauncher.RegressionTests.csproj --no-restore --nologo -v minimal -clp:ErrorsOnly -p:CustomAfterMicrosoftCommonTargets=E:/OneLauncherProject/OneLauncher/build/theme-icons-20261023/Validation.targets
dotnet tests/OneLauncher.RegressionTests/bin/Debug/net10.0/OneLauncher.RegressionTests.dll build/theme-icons-20261023
```

在其他检出目录运行时，请将 MSBuild 参数中的绝对路径改为该目录下的 `Validation.targets`。再次正常编译回归测试项目即可恢复原有测试程序。
