# 界面标识符显示开关

## 行为与用意

在设置页“界面”板块添加“是否显示标识符”复选框，统一控制账户列表 UUID、游戏数据列表 InstanceId 和服务器收藏列表关联 InstanceId 的可见性。隐藏的是整段标识符标签和数值，因此不会留下标签；账户类型、版本、加载器、服务器延迟及操作按钮继续正常显示。

`AppSettings.ShowIdentifiers` 默认值为 `true`，旧配置缺少该字段时保持原有显示行为。配置使用现有源生成 JSON 上下文持久化，无需迁移。

## 实现逻辑

- `OneLauncher.Core/Global/ModelDataMangers/DBManager.cs`：增加持久化字段。
- `OneLauncher/ViewModels/Pages/SettingsPageViewModel.cs`：维护开关及保存状态，异步调用现有 `DBManager.Save()`；保存期间禁用开关，失败恢复配置与复选框并交给现有异常处理器。
- `OneLauncher/ViewModels/Pages/AccountPageViewModel.cs`、`GameDataPageViewModel.cs`、`ServerPageViewModel.cs`：读取同一 DBManager 的设置，订阅弱引用 `IdentifierVisibilityChangedMessage`，在 UI 线程通知属性变更。账户页和游戏数据页通过构造函数注入 DBManager，现有依赖注入注册可自动解析。
- `OneLauncher/Views/Pages/settings.axaml`：添加双向绑定的复选框。
- `OneLauncher/Views/Pages/account.axaml`、`gamedata.axaml`、`server.axaml`：标识符 TextBlock 的 `IsVisible` 绑定到所属页面的 `ShowIdentifiers`。

设置初始化直接读取字段，避免初始化时重复保存。设置变更成功后发送专用消息，已有页面随即应用，无需重建列表或重启；以后创建的页面直接读取已保存设置。

## 后续扩展

同一页面新增标识符展示时，复用页面的 `ShowIdentifiers` 绑定即可。新页面可注入 DBManager，公开该属性，并订阅同一弱引用消息通知视图。当前不隐藏版本号或用户主动输入的服务器地址。
