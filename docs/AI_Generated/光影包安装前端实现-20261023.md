# 光影包安装前端实现

日期：2026-10-23。

## 功能与用意

现有“资源检索”页面已接入光影搜索和安装。工具栏按“搜索框、资源类型下拉框、搜索按钮”横向排列，下拉框提供“模组”和“光影包”。两种资源共用既有 `InstallModPane`、其 ViewModel 与工厂，不新增光影专用 Pane 或导航页面。

用户选择光影包后，可选择原版、Fabric、Forge、NeoForge 或 Quilt 游戏实例安装。前端不检查 Iris、OptiFine 等依赖是否安装，光影模式隐藏“同时下载依赖”选项。SHA1 设置继续读取全局配置，文件保存和校验仍由后端负责。

## 代码逻辑

### 搜索与展示

`SearchModrinth.ToSearch` 增加可选 `ResourceType` 和取消令牌，原单参数调用仍搜索模组。模组保留原有分类条件；光影只使用 `project_type:shader`。关键词与筛选条件经过 URL 编码，共享客户端响应与读取流按请求释放，JSON 使用现有源生成上下文。

`ResourceItem` 从搜索结果提取公共展示字段并保存资源类型。安装按卡片自身类型分派，避免依赖页面当前选择。模组读取各加载器分类，包括 Forge、Quilt；光影保留完整 Minecraft 版本标识，不套用正式版过滤。

浏览 ViewModel 继续实现 `IPageHost` 和 `IListTemplate<ResourceItem>`。类型改变后刷新搜索，后续搜索取消旧请求，并通过请求序号避免较迟返回的结果覆盖最新列表。页面显示加载、无结果和失败状态，清除按钮随输入内容更新，搜索按钮及 Enter 仍共用搜索命令。异常交由现有 `OlanExceptionWorker`。

### 共用安装侧栏

`InstallModPaneViewModel` 接收 `ResourceItem`、共享实例管理器、`UnitedCore`、`DBManager` 和关闭回调。工厂增加对既有配置单例的构造注入；现有工厂注册无需新增或替换。

侧栏按资源类型显示标题、依赖选项及提示。模组保留加载器和版本校验，调用 `InstallMod`；光影跳过这两项模组前置限制，调用 `InstallShaderPack`，具体兼容版本由后端确认。开始前检查目标实例仍存在且版本标识有效，运行期间禁用目标编辑和重复安装。

支持版本列表改为默认折叠，保证最小窗口下安装状态可见。状态框提供图标、文字、边框与背景颜色，区分等待/运行、完成、取消和失败。

### 任务与取消

两种资源复用同一 `TaskManager`，安装时创建任务并传入其取消令牌。Pane 的进度与任务中心同步；运行中的百分比最多显示 99%，后端方法成功返回且未取消后才设置 100% 与完成状态。

进度回调检查任务身份、运行状态及当前安装状态，避免取消、重试或完成后的迟到通知覆盖终态。取消异常独立处理，不报告安装成功或未知错误；失败进入现有异常展示。

“取消安装”取消当前任务，返回操作在安装运行中同时取消并关闭。旧 Pane 的关闭回调仅作用于仍由它占用的页面侧栏，不关闭已经替换的新 Pane。开始和成功通知支持点击打开既有任务中心。

为使共用 Pane 的模组取消行为完整，`GetModrinth.Init` 增加取消令牌与依赖开关，元数据和依赖请求传递令牌并释放响应；取消异常直接传播。关闭依赖选项时跳过依赖查询，原零参数调用保留默认行为。`InstallMod` 未找到匹配版本时现在抛出业务错误，避免无文件安装被前端标记成功。
