# 命名空间调整后的引用修复

## 用意与范围

保留现有目录迁移与命名空间声明，修复迁移后遗漏的引用，不调整业务逻辑。

## 修复逻辑

- 下载与 JVM 参数构建代码中的 ForgeSeries、Quilt 引用改为实际的 `Resource.Mod.Loader` 命名空间。
- Fabric 下载提供器引入已迁移的 Fabric 解析器命名空间；下载组件与 Fabric/Quilt 提供器引入已迁移的 Modrinth 服务命名空间。数据模型仍使用其现有声明。
- `App.axaml` 与 `Styles/Styles.axaml` 的资源 URI 改为 `avares://OneLauncher/Styles/`，对应样式文件的实际位置。
- ConsoleTest 与 Forge 测试的导入和反射类型名称同步到 ForgeSeries 新命名空间；界面回归测试的工厂反射名称和依赖注入筛选同步到实际的 `OneLauncher.ViewModel.PaneViewModels.Factories`。

## 后续扩展

后续移动类型时，需同时检查 C# 导入、AXAML 资源 URI、以及反射使用的完整类型名称。目录与命名空间不一定一致，应以实际类型声明为准；本次未扩大为统一重命名。
