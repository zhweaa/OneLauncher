# 标签下拉框重置操作

日期：2026-10-23。直接修改实际项目。

游戏数据页工具栏移除独立“重置”按钮。标签下拉框依次显示“新建标签...”“重置筛选”，然后显示用户标签。选择“重置筛选”恢复全部实例、清空选中项并显示原占位文字，不打开新建标签 Flyout，也不修改标签定义、实例标签关联或保存文件。普通筛选、空结果与未筛选状态均可执行。

## 实现文件

| 文件 | 变更 |
|---|---|
| OneLauncher/Views/Pages/gamedata.axaml | 移除独立重置按钮 |
| OneLauncher/ViewModels/Pages/GameDataPageViewModel.cs | 新增 IsResetAction 与 ResetAction；列表加入重置特殊项；选中后复用重置逻辑；刷新仅按真实标签 ID 恢复选择 |
| OneLauncher/Views/Pages/gamedata.axaml.cs | 两种特殊项均清空控件选择，只有创建项打开 Flyout |
| docs/AI_Generated/UI_FI.md | 补充两种特殊项规则 |

特殊项不伪造 GameDataTag，CanDelete 仅对真实标签返回 true。刷新列表不能按 null ID 恢复重置项，否则重置后字段会再次显示特殊项。

业务重置仍在 ViewModel 中处理。View 负责清空 ComboBox 的视觉选择，与原创建特殊项共用处理，避免双向绑定更新期间控件仍显示“重置筛选”。以后新增动作项应继续明确区分标签数据和界面动作。
